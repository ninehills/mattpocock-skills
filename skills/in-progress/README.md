# 进行中

仍在开发中的技能。尚未准备好发布——预期会有粗糙的边缘、破坏性变更和被放弃的实验。在毕业到稳定分类之前，它们被排除在插件和顶级 README 之外。

- **[review](./review/SKILL.md)** — 沿两个并行轴审查自某个固定点以来的变更：**标准**（diff 是否遵循仓库的编码规范？）和**规格**（diff 是否忠实实现了原始 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** — 将文章塑造成节拍之旅，类似选择你自己的冒险风格。选择一个起始节拍，仅写该节拍，然后转向下一个，直到文章自然结束。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 追问式会话，挖掘你的片段——异质的写作素材——并将其附加到单个文档中作为未来文章的原始材料。
- **[writing-shape](./writing-shape/SKILL.md)** — 获取原始材料的 markdown 文件，逐段将其塑造成文章，在每一步讨论格式选择。
