# 进行中 (In Progress)

仍在开发中的技能。尚未准备好发布 —— 预计会有粗糙的边缘、破坏性变更和被放弃的实验。在毕业到稳定分类之前，它们被排除在插件和顶层 README 之外。

> Skills that are still being developed. They're not ready to ship — expect rough edges, breaking changes, and abandoned experiments. They're excluded from the plugin and the top-level README until they graduate to a stable bucket.

- **[review](./review/SKILL.md)** — 从一个固定点沿两个平行轴审查变更：**标准**（diff 是否遵循仓库的编码规范？）和**规格**（diff 是否忠实地实现了原始 issue/PRD？）。
  > Review changes since a fixed point along two parallel axes: **Standards** (does the diff follow the repo's coding standards?) and **Spec** (does the diff faithfully implement the originating issue/PRD?).
- **[writing-beats](./writing-beats/SKILL.md)** — 将文章塑造成节拍旅程，采用选择你自己的冒险风格。选择起始节拍，只写该节拍，然后转向下一个，直到文章自然结束。
  > Shape an article as a journey of beats, choose-your-own-adventure style. Pick a starting beat, write only that beat, then pivot to the next, until the article reaches a natural end.
- **[writing-fragments](./writing-fragments/SKILL.md)** — 矿掘会话，从你身上挖掘碎片 —— 异质的写作小块 —— 并将它们作为未来文章的素材追加到单个文档中。
  > Grilling session that mines you for fragments — heterogeneous nuggets of writing — and appends them to a single document as raw material for a future article.
- **[writing-shape](./writing-shape/SKILL.md)** — 拿到一份原始素材的 markdown 文件，逐段将其塑造成文章，在每一步讨论格式选择。
  > Take a markdown file of raw material and shape it into an article paragraph by paragraph, arguing format choices at each step.
