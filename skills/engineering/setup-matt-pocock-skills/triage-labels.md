# 分诊标签 (Triage Labels)

技能以五个规范分诊角色的术语进行表述。此文件将这些角色映射到此仓库 issue 跟踪器中使用的实际标签字符串。

> The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 完全指定，准备就绪可由 AFK agent 认领 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会被处理 |

| Label in mattpocock/skills | Label in our tracker | Meaning |
