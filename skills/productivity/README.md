# 生产力

通用工作流工具，非代码专用。

- **[caveman](./caveman/SKILL.md)** — 超压缩通信模式。通过去除填充词，在保持完整技术准确性的同时，将 token 使用量减少约 75%。
- **[grill-me](./grill-me/SKILL.md)** — 对某个计划或设计进行持续追问，直到决策树的每个分支都得到解决。
- **[handoff](./handoff/SKILL.md)** — 将当前对话压缩为交接文档，以便另一个代理可以继续工作。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建具有适当结构、渐进式披露和捆绑资源的新技能。
