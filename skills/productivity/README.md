# 效率工具 (Productivity)

通用工作流工具，不限于代码相关。

> General workflow tools, not code-specific.

- **[caveman](./caveman/SKILL.md)** — 超压缩沟通模式。去掉废话但保留完整技术准确性，token 用量减少约75%。
  > Ultra-compressed communication mode. Cuts token usage ~75% by dropping filler while keeping full technical accuracy.
- **[grill-me](./grill-me/SKILL.md)** — 对你的计划或设计进行无情的访谈，直到决策树的每个分支都得到解决。
  > Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[handoff](./handoff/SKILL.md)** — 将当前对话压缩为交接文档，以便另一个 agent 继续工作。
  > Compact the current conversation into a handoff document so another agent can continue the work.
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建具有正确结构、渐进式披露和捆绑资源的新技能。
  > Create new skills with proper structure, progressive disclosure, and bundled resources.
